# Select Dataset Columns using Pandas

## Overview
This project is part of the Veda Technology AI & ML Internship. It demonstrates how to select specific rows and columns from a dataset using Pandas indexing methods.

The Iris dataset is used to practice label-based and position-based data selection.

## Objective
To understand how to extract specific information from a Pandas DataFrame using `loc[]` and `iloc[]`.

## Dataset
- **Dataset:** Iris Dataset
- **File:** `Iris.csv`
- **Format:** CSV
- **Description:** Contains flower measurements and species information.

## Technologies Used
- Python
- Pandas
- Google Colab

## Concepts Covered
1. Loading a CSV dataset using Pandas.
2. Exploring dataset dimensions and column names.
3. Selecting rows and columns using `loc[]`.
4. Selecting rows and columns using `iloc[]`.
5. Selecting single and multiple columns.
6. Filtering records based on flower species.

## Implementation

### 1. Using loc[]
The `loc[]` method selects rows and columns using their labels.

Examples:
- Selecting specific rows and named columns.
- Extracting a single column.
- Selecting multiple columns.
- Filtering records based on conditions.

### 2. Using iloc[]
The `iloc[]` method selects rows and columns using integer positions.

Examples:
- Selecting the first five rows.
- Extracting columns by their positions.
- Selecting specific row and column ranges.

## Key Learning Outcomes

- Learned how to select specific columns from a dataset.
- Practiced row and column indexing.
- Improved Pandas DataFrame manipulation skills.
